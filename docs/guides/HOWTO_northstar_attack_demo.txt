The Demo Binary (l2_northstar_attack_resistance_demo.c)
- Self-contained C99 + POSIX + Linux (no external libs).
- Hardcoded DIABOLICAL_PAYLOAD[10] uint64 bit patterns (the "sent" payload).
- Supports:
  - Default / --recv-payload [file]: load payload from "net sim" hex file (one 16-hex-digit line per uint64, as produced by --gen). Reinterprets bits as doubles/ints with ZERO sanitization (no isnan, no isfinite, raw casts, accum, pun, loop with subnormals). Runs all 4 demonstrate vectors + grand + summary.
  - --gen-payload-hex: outputs the exact 10 lines of hex (the "send" of the crafted bits; can be put to a channel object/file via l2 put, or na-injected over the masked surface).
- is_in_l2_workspace() (stricter for root-local safety): looks for l2-ws- in cwd/HOME, L2_DATA_DIR signals, or combo of USER/LOGNAME=="l2" (set by l2's setup_minimal_l2_env) + l2- evidence. Hardened specifically for your "run as pure root locally on own machine" test case.
- Root-local pure-root testing security (your plan):
  - Direct root run (sudo ./ns or in /root or normal /tmp without l2-ws- markers, no L2_DATA_DIR ws, USER=root) will hit euid==0 warning + is_in=false.
  - ALL "success" side-effects (the 4 northstar_*.txt marker files that simulate bypass-grant, timing-leak-of-secret, overflow-OOB, consensus-split "escalation") are double-gated: if (is_in_l2_workspace()) { fopen... }.
  - No absolute paths, no writes to /etc /root /sensitive, no system()/exec of attacker payloads, no real C2 (sockets only in related demos). Markers are always relative to cwd *and only if in*.
  - Even as pure root locally, the demo will not compromise your machine (beyond files you deliberately create in your test cwd). You get the rich math evidence output for demonstration, but BLOCKED for actions.
  - The real North-Star Defense requires the l2 usage model (create ws under great-harden + Landlock/seccomp/env sanitization on top of the demo's internal guards).
- All "damage" and "secrets" are simulated safely (reversible text markers, no real host harm). The "payload" is the static bits (in real attack: received from net as 8-byte doubles or int fields in any numeric stream).
