# l2 — Minimal High-Assurance System Substrate (v0.1.0)

Terminal-first tool for creating, using, and destroying strongly isolated execution contexts. Driven from the shell. Built for high-assurance with seL4 as the target root of trust.

**Linux prototype** for immediate development and validation. **seL4/Microkit** for production/high-assurance workloads.

## Quick Start

```bash
cargo build --release
l2 --help

# Prototype usage
l2 create my-agent --policy strict
l2 put my-agent task.rs --type code --content 'fn main() { println!("Hello from l2"); }'
l2 exec my-agent ./task
l2 destroy my-agent

# High-assurance seL4 setup
l2 sel4-setup
```
