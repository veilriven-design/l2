RECOMMENDED EXACT SEQUENCE (copy-paste into a real interactive terminal; use L2_DATA_DIR for hermetic test)

```bash

l2 create crypto-redteam --policy great-harden

# 5. Put the demo source into the workspace (this is the ONLY place the attacks are "allowed" to succeed in sim; explicit put authority)
l2 put crypto-redteam crypto-redteam.c --file docs/examples/l2_crypto_redteam_onslaught.c

#    gcc -static -Wall -Wextra is used so the binary only needs the tiny set of RO paths allowed by Landlock under great-harden.
```
